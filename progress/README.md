# progress/

Screenshots and recordings of the prototype.

**This folder is currently empty.** Nothing has been put in it yet, because of
what the next section says.

## What may go in here

Only material that is honest about two things: **whose work it shows**, and
**what in it is a placeholder**.

That is a real constraint, not a formality. The prototype's environment blockout
and its lighting are **my project partner's work**. The character and its
animations are a third-party placeholder. The vision is stock footage, regraded.
The code is AI-written. So a screenshot of the running game is not a screenshot
of my art — and captioning it as if it were would be the exact thing this
repository is trying not to do.

What is honest to show, and how:

| What | Caption it as |
|---|---|
| A prototype walkthrough recording | "Prototype walkthrough. Environment blockout and lighting by my project partner; character, animations and vision are third-party placeholders; all code AI-written. My work here: scene assembly, systems wiring and the build." |
| Placeholder objects or test scenes I built myself | "My own blockout / test setup." Only for things I actually made |
| A diagram of the task plan and dependencies | "My work" — this one is genuinely mine, and it is the best thing I could add |
| Design documents and the map, as images | "Co-written with my project partner" |

## What must never go in here

- Anything naming the novel, its author, its characters or its places.
- Frames showing clue names or the case file — the clue titles come from the
  adapted case. Avoid those frames, or crop them out.
- The third-party character or animations as files; frames of it in motion are
  fine if captioned as a placeholder.
- The stock vision footage as a file, and any frame of it presented as our art.
- Any image from the reference folder. Those were gathered off the internet and
  generated with an image tool; none of them are ours to publish.

## Caption format

One `.md` file per item, or one line per item in this README:

```
### 2026-10-20 — prototype walkthrough
![alt](walkthrough-2026-10-20.gif)
Shows: three scents, one vision, the clue counter filling, the end card.
My work: scene assembly, systems wiring, the web and Windows builds.
Partner's work: environment blockout, lighting and grade.
Placeholders: character, animations, vision footage.
```

Keep files small — a short GIF or a compressed MP4, not a raw capture. This
repository should stay cheap to clone.
